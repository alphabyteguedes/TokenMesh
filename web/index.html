        02 · Engenharia Zero-Infra
        

          Toda a pilha de gateway colapsada em um único arquivo DuckDB.
        

      


      

        
        
        

          

            

              DUCKDB VSS · HNSW COSINE INDEX
              P99 < 2.4ms
            

            
Busca Vetorial In-Process Sub-Milissegundo

            

              Esqueça clusters externos de Redis ou Qdrant. O TokenMesh armazena vetores FLOAT[384] com índices HNSW persistidos diretamente no arquivo tokenmesh.duckdb, eliminando saltos de rede e serialização TCP.
            

          


          
          

            

              

                TokenMesh (DuckDB In-Process HNSW)
                1.8 ms
              

              

                

              

            

            

              

                Gateway Tradicional + Redis + Cloud Vector DB
                64.0 ms
              

              

                

              

            

          

        


        
        

          

            

              ZERO-TRUST DLP · LGPD & GDPR
              CPU Regex
            

            
Sanitização Automática de PII

            

              Mascara CPF, CNPJ, cartões de crédito, e-mails corporativos e chaves sk-* localmente antes do prompt sair da sua rede privada.
            

          


          

            

              Input: "Cliente CPF 123.456.789-00"
